# Portfolio

The personal portfolio site of Jackson Sammy, a data engineer: Case Studies, résumé, about, and writing. A fast, static site built with [Astro](https://astro.build) and hosted on Vercel's free Hobby plan.

Work on this site is tracked as tickets in [JacksonSammy/zcode-project](https://github.com/JacksonSammy/zcode-project/issues).

## Run it locally

Requires Node 22.12 or newer.

```sh
npm install
npm run dev      # dev server at http://localhost:4321
npm run build    # static build into dist/
npm run preview  # serve the built site locally
```

## Deploying

Pushing to `main` auto-deploys to production on Vercel through the GitHub integration; pull requests get preview deployments. Vercel Web Analytics is enabled on the project.

The site is intentionally personal and non-commercial, per the [Vercel Hobby plan's fair-use guidelines](https://vercel.com/docs/limits/fair-use-guidelines).
